# Changelog

## Unreleased local foundation candidate — 2026-10-14

### Added

- Five new original reference designs alongside Segmented Comet: Assembly Progress,
  Border Runner, Telemetry Embers, Pocket Mascot and Prism Reveal
- Exact-width allocated inline output; separate masked replacement and field-limited
  style surfaces; typed progress/level validation; finite visual completion
- Bounded authored-frame schema, deterministic checked-in Rust generation and
  direct unequal-hold frame selection
- Optional rational playback, freeze/catch-up policies and pure repaint planning
- Three host-owned integration examples and four synthetic protected layouts
- Six-design gallery, manifests, real styled-cell captures and fixed-font previews
- Independent contract/property tests and runtime-only CrossWeave extension fixture
- Warmed painting, allocation, output and downstream binary/dependency audits
- Bounded Linux release-host PTY endurance/resource evidence and seeded lifecycle
  event-storm tests; archived measured executables, sources and replayable captures

### Fixed during independent review

- Oversized Border Runner requests no longer generate useless animation wakes
- Unsupported-width reveal styling is limited to its own measured text footprint
- Zero-column text no longer requests invisible animation
- Redundant and rationally equivalent playback commands preserve fractional phase
- Compound example-host rate-change/pause commands preserve the actual displayed
  pose; restart, generation replacement and new completion invalidate saved poses
- Qualification harness now checks active-output liveness and inclusive erase-to-
  beginning; original observations and retrospective checks remain distinguished

### Release limits

This is local source/evidence, not a published package. Licensing/public names,
remote publication, native macOS/Windows execution and terminal/font/tmux/SSH
qualification remain unresolved. See docs/foundation-status.md for exact evidence
and omissions; no configured CI job is presented as a passing remote run.
